# The 0.2.0 demo (host/render_v020.sh): the seams of E3 + E4 + E5 in one project, through panel input only (0.6.0's
# gestures, docs/UX-V2.md). T1 drums with an insert (DESTROY) + a send to S1 (REVERB); T2 the NEIGH machine behind T1;
# T3 the bass in HARMONIZER with LFO 1 on PITCH; T4 the percussion on R.POLY; scenes A / B over E3, E4 and bus params
# (CROSSFADER: B11 held + B1 / B2 = capture) and a glide (W12 held); pattern A1 copied onto A2 (PATTERN LAUNCH, F1);
# saved (SHIFT + FILE). render_v020.sh then reboots from the flash. A fresh project with build/demo_folder
# (host/make_demo_folder.py). Times are device ms; lower I = white key W(I+1) (0..15), upper I = black key B(I+1)
# (0..10). Tracks are SHIFT + W1..W9; samples load from FILE (SEL the cursor, B10 = LOAD into the next free slot, the
# track plays it); a mode's setup is SHIFT + its button (or a hold; HOME held = the machine / warp setup), F1 closes.
